# Little Inferno co-op

Two players at one fireplace on PC: player 1 with the mouse, player 2 with a gamepad, both
grabbing, throwing and burning at the same time. Coins, stamps and the save are shared, the
way the Switch edition's co-op works.

The PC engine already has a second pointer (multi-touch leftover); only the first was ever
fed. This mod feeds the second one from a gamepad and draws its cursor. No game files are
changed: the mod is a `winmm.dll` that sits next to the game and forwards everything else to
Windows' own winmm.

Made with [Co-op Anything](https://github.com/cranebeaker/coop-anything); engine notes for
other modders are in its `games/little-inferno` folder.

## Requirements

- Little Inferno **from Steam, build 10124709** (version 2.0.3, the Ho Ho Holiday update). On
  any other build the mod switches co-op off by itself and the game runs as usual.
- Windows 10 or 11, a mouse, and a DualSense, DualShock 4 or XInput (Xbox) pad.

## Install

1. Download `LittleInferno-Coop.zip` from [Releases](../../releases) and unzip it anywhere.
2. Close the game and run `install.bat`. If the game is not in Steam's standard folder:
   `install.bat "D:\Games\Little Inferno"`. (Steam installs it as `Little Inferno Beta`.)
3. Start the game and plug in the pad.

Uninstall with `uninstall.bat`, or Steam's "Verify integrity of game files".

## Controls (player 2)

| | |
|---|---|
| Left stick | move the cursor |
| Cross / A, or R2 | hold on an item to grab it, release to drop or throw; hold on empty space to make fire |

In the fireplace both players can grab and throw items, make fire, pull items from the tray
and read letters. The catalog uses the same button code as the letters but has not been
tried by player 2 yet. The title, mode and slot menus are player 1 only.

## Settings

`licoop.ini` next to `Little Inferno.exe`. Saved changes apply while the game runs.

| Setting | |
|---|---|
| `enabled` | 0 turns the mod off without uninstalling it |
| `cursor_speed` | screen heights per second at full stick (default 0.9) |
| `stick_dead_zone` | 0..1 (default 0.15) |
| `cursor_size`, `cursor_color` | ring radius in pixels, colour as `RRGGBB` |
| `saves_dir` | keep saves in this folder instead of `%APPDATA%\Little Inferno` (for test copies) |

## Known issues

- Tested in the first part of the game (tutorial, first letters). Later catalogs, the
  ending and Ho Ho Holiday mode are not checked yet.
- Player 1's cursor is the normal Windows cursor; player 2's is a ring drawn by the mod.
- Not tested with Steam Input enabled for the pad.

## Build

Needs Visual Studio 2022+ (or Build Tools) with C++ and the x86 libraries.

```
build.bat                     rem build only: build\winmm.dll, package\winmm.dll
build.bat "<game folder>"     rem build and copy into that folder
```

`src/winmm_forwards.h` is generated by `tools/gen_winmm.py` from `SysWOW64\winmm.dll`.
`ghidra/` holds headless Ghidra scripts that dump every function; `tools/` has a decompile
browser, a disassembler and PowerShell helpers that start a test copy, click, drag and take
screenshots. Player 2 can be driven without a pad by writing `x y button` (x, y in 0..1,
button 1 down, 0 up, -1 absent) to `licoop_cmd.txt` next to the exe.

## По-русски

Кооператив на двоих для Little Inferno на PC: игрок 1 мышью, игрок 2 геймпадом, один камин,
общие монеты и сохранение. Оба одновременно хватают, бросают и поджигают.

Установка: скачайте `LittleInferno-Coop.zip` в [Releases](../../releases), закройте игру,
запустите `install.bat`. Нужна Steam-версия (сборка 10124709). Управление игрока 2: левый
стик — курсор, крестик/A или R2 — схватить предмет или, на пустом месте, огонь. Меню вне
камина — только для игрока 1. Настройки курсора — в `licoop.ini` рядом с игрой, меняются на
лету. Удаление: `uninstall.bat`.
