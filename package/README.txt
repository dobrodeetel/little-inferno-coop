Little Inferno co-op
====================

Two players at one fireplace on one PC: player 1 with the mouse, player 2 with a
gamepad (DualSense, DualShock 4 or any XInput / Xbox pad). Both can grab and throw
items, light fires, read letters and use the catalog. Coins, stamps and the save
are shared. Menus outside the fireplace (title, slot select) are player 1 only.

Requires Little Inferno from Steam, build 10124709 (version 2.0.3). On any other
build the mod switches itself off and the game runs as usual.

Install:   close the game, run install.bat
           (other folder: install.bat "D:\Games\Little Inferno")
Uninstall: uninstall.bat, or Steam > Verify integrity of game files

Player 2:  left stick   move the cursor
           Cross / A    hold to grab, release to drop; hold on empty space for fire
           R2           same as Cross / A

Settings:  licoop.ini next to the game, re-read while the game runs.
Log:       licoop.log next to the game.
